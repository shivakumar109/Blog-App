Blog App ✍️

A simple and modern blogging platform built with the MERN Stack where users can share their thoughts, write blogs, and explore posts from others.

This project was created to practice and improve full-stack development skills using React, Node.js, Express, and MongoDB.

🚀 About The Project

Blog App is a full-stack web application that allows users to:

Create and publish blog posts
Edit or delete their own blogs
Read blogs posted by others
Register and log in securely
Experience a clean and responsive UI

The project focuses on building a complete CRUD application with authentication and database integration.

⚙️ Getting Started
1. Clone the Repository
git clone https://github.com/shivakumar109/Blog-App.git
cd Blog-App
🔧 Backend Setup

Move into the server folder:

cd server

Install dependencies:

npm install

Create a .env file inside the server folder:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

Start the backend server:

npm run dev
 Frontend Setup

Move into the client folder:

cd client

Install dependencies:

npm install

Run the frontend:

npm run dev
